# 观势

一个基于《易经》卦象的状态判断与行动建议工具。

它不把《易经》做成简单的算命答案机，而是把卦象理解为关于“时、位、势、变”的观察系统：

- 静态：用户当下所处的状态、位置、关系和局面。
- 动态：局势下一步可能如何变化，以及用户更适合采取什么行动姿态。

## 当前版本

v0.2 已包含：

- 64 卦基础库
- 随机起卦、本卦、变卦、变爻
- 问题场景识别：事业、项目、关系、选择、情绪、财务、学习、综合
- 当前状态、变化趋势、行动建议、不宜提醒
- 一句话总结
- 复制结果
- 最近记录，本地浏览器保存

## 问题与卦象如何对应

用户输入的问题不会硬性决定卦象。卦象仍通过随机起卦生成，以保留仪式感和不确定性。

用户问题用于识别语境，例如项目、关系、事业或情绪。系统会用这个语境调整解读角度和行动建议。

简单说：问题提供语境，卦象提供时位。
